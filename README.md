# SmartphoneProgramming_TermProject

프로젝트 제목 : Tundra Survivors

게임 컨셉 : 다가오는 몬스터들을 피하면서 공격하여 성장하는 탑뷰 슈터(뱀서라이크)

개발 범위 : 
플레이어 캐릭터 1종과 액티브 2종(투사체, 주변 범위공격), 패시브 6종(최대 체력증가, 생명력 흡수, 이동속도 증가, 투사체 속도, 투사체 숫자, 공격범위)
적 몬스터 4종(기본 추적, 시간제 돌진, 원거리 공격, 보스)
체력회복 아이템

1주차 04/06~04/12 : 리소스 준비
2주차 04/13~04/19 : 플레이 씬에서 플레이어 이동/애니메이션
3주차 04/20~04/26 : 기본추적 몬스터 구현(생성, 추적,충돌) 
4주차 04/27~05/03 : 돌진,원거리 공격 몬스터 구현
5주차 05/04~05/10 : 몬스터 피격/사망처리 및 경험치획득, 레벨업 시스템(pause 및 선택지)
6주차 05/11~05/17 : UI, 게임 상태 관리
7주차 05/18~05/24 : 배경, 사운드 적용
8주차 05/25~05/31 : 보스 구현 및 마무리
